## Projects

### LLM & RAG Systems
**[READLY](https://github.com/khadijaa-ali/READLY-Read-Learn-Analyze-)** – Read · Learn · Analyze
A RAG document Q&A system. Upload a PDF or Word file and ask questions — answers come only from the document, not the model's general knowledge. Built with LangChain, Mistral AI, and FAISS, with a tuned chunking/retrieval pipeline (`k=5`) and full source-chunk transparency for every answer.

### Agentic AI & Automation
**[Scholar Router (n8n Workflow)](https://github.com/khadijaa-ali/n8n-scholar-router)**
An n8n workflow that classifies incoming messages into 4 intent types and routes each to a different LLM chain using conditional Switch/If logic. Solved a tricky back-reference bug in multi-branch routing — now a reusable fix for similar n8n workflows.

### Machine Learning
**[Heart Disease Prediction App](https://github.com/khadijaa-ali/Heart-Disease-Prediction)**
Streamlit app that predicts heart disease risk from patient health details. Compared Logistic Regression and SVM; used StandardScaler and Joblib for real-time predictions.

**[GovAI Transparency Portal](https://github.com/khadijaa-ali/GovAI-Transparency-Portal)**
End-to-end ML platform for detecting anomalies in government procurement data. Built with Random Forest (98.1% accuracy, 97.3% ROC-AUC) and XGBoost, plus 5 interactive Plotly/Seaborn visualizations and a bilingual (Urdu/English) chatbot. Top 50 Projects — Uraan AI Techathon 1.0 (Solo, Oct 2025)

**[SmartPhone Price Predictor](https://github.com/khadijaa-ali/SmartPhone-Price-Predictor)**
Predicts mobile price category using XGBoost and exact price using Random Forest Regressor. Compared 3 classifiers and 3 regressors on Accuracy, F1, ROC-AUC and MAE. Interactive Streamlit app with confidence bars and real-time estimates.
