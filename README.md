## Projects

### LLM & RAG Systems
**[READLY](https://github.com/khadijaa-ali/READLY-Read-Learn-Analyze-)** – Read · Learn · Analyze
A Retrieval-Augmented Generation (RAG) document Q&A system. Upload a PDF or Word document and ask questions — answers are generated only from retrieved content, not the model's general knowledge. Built with LangChain, Mistral AI, and FAISS, with a custom-tuned chunking and retrieval pipeline (`k=5`) and full source-chunk transparency for every answer.

### Agentic AI & Automation
**[Scholar Router (n8n Workflow)](https://github.com/khadijaa-ali/n8n-scholar-router)**
n8n automation workflow that classifies incoming messages into 4 intent types and routes each to a different LLM chain or agent using conditional Switch/If logic. Solved a tricky back-reference expression bug in multi-branch routing — now a reusable fix pattern for any multi-branch n8n workflow.

### Machine Learning
**[Heart Disease Prediction App](https://github.com/khadijaa-ali/Heart-Disease-Prediction)**
Streamlit web app that predicts heart disease risk using patient health details. Trained and compared Logistic Regression and SVM; applied StandardScaler and Joblib for real-time ML predictions.

**[GovAI Transparency Portal](https://github.com/khadijaa-ali/GovAI-Transparency-Portal)**
End-to-end ML platform for detecting anomalies in government procurement data. Built with Random Forest (98.1% accuracy, 97.3% ROC-AUC) and XGBoost. Includes 5 interactive Plotly/Seaborn visualizations and a bilingual (Urdu/English) chatbot. Selected among Top 50 Projects — Uraan AI Techathon 1.0 (Solo Submission, Oct 2025)

**[SmartPhone Price Predictor](https://github.com/khadijaa-ali/SmartPhone-Price-Predictor)**
Dual-model ML app that predicts mobile price category (Budget / Mid-Range / Upper Mid-Range / Premium) using XGBoost Classifier and estimates exact price using Random Forest Regressor. Compared 3 classifiers and 3 regressors; selected best models based on Accuracy, F1-Score, ROC-AUC and MAE. Interactive Streamlit app with confidence bars per class and real-time price estimation.
